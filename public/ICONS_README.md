# PWA Icons

Für die PWA benötigst du folgende Icon-Dateien im `public/` Ordner:

## Benötigte Dateien:

1. **favicon.ico** (32x32 px)
2. **apple-touch-icon.png** (180x180 px)
3. **pwa-192x192.png** (192x192 px)
4. **pwa-512x512.png** (512x512 px)

## Icon erstellen:

### Option 1: Online Tool (empfohlen)
1. Gehe zu [favicon.io](https://favicon.io/favicon-generator/)
2. Wähle ein Fussball-Emoji ⚽ oder erstelle ein eigenes Design
3. Generiere die Icons
4. Lade das Paket herunter
5. Kopiere die Dateien in den `public/` Ordner

### Option 2: Eigenes Design
1. Erstelle ein quadratisches Logo (mindestens 512x512 px)
2. Nutze ein Tool wie [realfavicongenerator.net](https://realfavicongenerator.net/)
3. Lade alle generierten Dateien in `public/`

### Schnellstart (Temporär)
Für den Start kannst du einfache einfarbige Bilder mit einem ⚽ Emoji verwenden:
- Öffne [placeholder.com](https://placeholder.com/)
- Erstelle Bilder in den benötigten Größen mit grünem Hintergrund
- Füge ein ⚽ Emoji hinzu

## Wichtig:
Ohne diese Icons wird die PWA-Installation trotzdem funktionieren, aber ohne eigene Icons.

Die App wird dann die Browser-Standard-Icons verwenden.
